# 小爪助手 · 安装与使用

一个常驻桌面的小助手：宠物只是它的脸，真正在干活的是
**待办 + 番茄钟 + 提醒 + 便签 + AI 操作**。
数据全部保存在你自己的电脑上，不联网、不上传。

---

## 安装

双击 `小爪助手-x.x.x-安装包.exe`，一路下一步。

安装时有两个可选项：

- **创建桌面快捷方式** —— 按需勾选
- **开机时自动启动小爪** —— 想让它常驻就勾上，之后也能在设置里改

装完会自动启动。程序会出现在系统托盘（右下角），找不到小爪时看那里。

### 系统要求

- Windows 10 或更高（64 位）
- 不需要单独安装 Python，运行库已经打包进去了

### 卸载

「设置 → 应用 → 小爪助手 → 卸载」，
或者在开始菜单里点「卸载 小爪助手」。

**卸载不会删除你的数据**（待办、便签、设置都在 `%APPDATA%\PawPet`）。
卸载过程中会问你要不要一起删掉，默认保留，方便以后重装继续用。

## 怎么用

| 操作 | 结果 |
| --- | --- |
| **单击小爪** | **就地弹出指令栏，打完回车就走** |
| 双击小爪 | 打开工作台 |
| 按住左键拖动 | 换位置，**位置会自动记住** |
| 右键小爪 | 快捷菜单（点别处或按 Esc 关闭） |
| 鼠标悬停 | 显示当前状态 |
| 左键单击托盘图标 | 显示 / 隐藏小爪 |

### 全局快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + 空格` | **唤出指令栏**（最常用） |
| `Ctrl + Alt + P` | 打开工作台 |
| `Ctrl + Alt + T` | 开始 / 暂停专注 |
| `Ctrl + Alt + N` | 直接跳到待办页 |

都能在「设置」里改。如果和输入法冲突，改掉即可。

### 换形象

设置页里有 **4 套形象**可以点选，都是实时预览的：
麻薯猫 / 柴犬 / 企鹅 / 小狐狸。

## AI 操作（可选）

这个功能能让 AI **看见你的屏幕、替你操作电脑**。不配置也能用，
只是「AI 操作」那一页会提示你去填 API Key。

### 配置

1. 打开「AI 操作」页 → 点「设置」按钮；
2. 填**接口地址**、**模型名**、**API Key**；
3. 点「测试连接」。

任何 **OpenAI 兼容**的接口都行：OpenAI、DeepSeek、Moonshot、通义、本地 Ollama…
**必须选支持视觉的模型**（比如 `gpt-4.1-mini`、`qwen-vl-max`），因为它要看截图。

API Key 只保存在你自己电脑的 `.env` 文件里，不会写进数据文件、不会上传。

### 能做什么

- 「屏幕上这个报错是什么意思」→ 截图分析并解释
- 「打开记事本，写下明天要做的三件事」
- 「帮我把这段话记成待办」
- 「把浏览器切到前台，点登录按钮」

### 安全设置（建议先读）

默认是**逐步确认**模式，每次会改变电脑状态的操作都会先弹卡片问你。

| 等级 | 行为 |
| --- | --- |
| 只读 | 只能看屏幕，任何会动键鼠的操作直接被拒 |
| **逐步确认**（默认） | 点击、输入、按键前都问你 |
| 自动执行 | 只读和键鼠自动跑，执行命令仍需确认 |
| 完全自动 | 不再询问（谨慎用，别开着它离开电脑） |

**三道保险：**

1. **急停**：把鼠标快速甩到屏幕左上角，立刻中断。
2. **危险命令黑名单**：`format`、`diskpart`、`shutdown` 之类直接拒绝执行。
3. **审计日志**：每次动作都记下来，在数据目录的 `.cache\ai-actions.log`。

> ⚠️ AI 的判断可能出错。请勿让它处理密码、支付信息、身份证号等敏感内容。

### 每轮最多执行步数

AI 页上有「执行步数」，默认 20 步，可调 10 / 20 / 30 / 50 / 100。

一步 = AI 看一次结果再决定下一步，一步里可以同时做几个动作，
所以 20 步通常够用了。任务做到一半就停 → 调大一点；
担心它自己操作太久或费用变高 → 调小一点。

## 数据在哪

| 安装方式 | 数据位置 |
| --- | --- |
| 安装版 | `%APPDATA%\PawPet`（在资源管理器地址栏粘贴这个就能打开） |
| 绿色版 | 程序所在文件夹 |

里面的东西：

```
pet_data.json            待办、便签、提醒、设置、专注统计
pet_data.backup.json     上一版的自动备份
.env                     你的 API Key（如果配了 AI）
.cache\ai-actions.log    AI 动作审计日志
.cache\sounds\           提示音（自动生成）
```

**备份就是复制这个文件夹。** 换电脑时把整个文件夹拷过去即可。

设置页里有「打开数据文件夹」按钮，不用自己找路径。

## 常见问题

**双击没反应？**
看系统托盘有没有小爪。它是常驻程序，不会出现在任务栏里。
如果托盘也没有，重新运行一次安装包修复安装。

**小爪不见了？**
托盘图标左键单击可以显示 / 隐藏。或者按 `Ctrl + Alt + P`。

**快捷键没反应？**
可能被别的程序占用了（输入法、截图工具都爱抢 `Ctrl+Alt+空格`）。
在「设置 → 全局快捷键」里换一组，然后点「立即重启」。

**想让它开机自动启动？**
「设置 → 启动 → 开机自动启动」打开即可。

**数据会不会丢？**
程序每次保存都会先写临时文件再原子替换，并且保留一份上一版备份。
主文件万一损坏，下次启动会自动从备份恢复并提示你。

**AI 一直说连不上？**
先点「测试连接」看具体错误。常见原因：Key 过期、地址少写了 `/v1`、
模型名不对、或者用了不支持图片的模型。

## 反馈

遇到问题请把这几样一起提供，方便定位：

1. 你做了什么操作
2. 期望的结果 vs 实际的结果
3. 数据目录里的 `.cache\ai-actions.log`（如果是 AI 操作的问题）
